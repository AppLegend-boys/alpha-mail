# Alpha-mail 로고 사용 가이드

**아이디어:** 말풍선이 α의 둥근 몸통이 되는 글자. "알파"와 "말로 하는 메일"을 한 형태에 담았다.

## 파일

| 용도 | 파일 |
|---|---|
| 심볼 마스터 | `final/symbol.svg` |
| 작은 크기(32px 이하) | `final/symbol-small.svg` — 선을 더 굵게 |
| 어두운 배경용 | `final/symbol-reversed.svg` — 반전 시 굵어 보이는 현상을 보정해 선을 살짝 얇게 |
| 가로형 / 세로형 | `final/horizontal.svg`, `final/stacked.svg` |
| 워드마크만 | `final/wordmark.svg` |
| 앱 아이콘 | `final/app-icon.svg`(둥근 모서리), `final/app-icon-full.svg`(정사각, 스토어·런처 마스크용) |
| 한 색·흑백·반전 | `export/*/…-black / -white / -mono-*.svg` + PNG |
| 웹 아이콘 | `export/symbol/` — `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`, `maskable-512.png`, `site.webmanifest`, `head-snippet.html` |
| 발표 보드 | `board.html`, `slides/*.png` |

## 색

| 이름 | HEX | RGB | 쓰임 |
|---|---|---|---|
| 민트 | `#A8F5D0` | 168 245 208 | 기본. 잉크 배경 위의 로고 |
| 잉크 | `#0D111B` | 13 17 27 | 기본 배경, 앱 아이콘 타일 |
| 딥 민트 | `#1E7A5A` | 30 122 90 | 흰색·밝은 배경 위의 로고 (흰색 대비 5.3:1) |

- 민트 ↔ 잉크 대비 15:1.
- **민트를 흰 배경에 쓰지 말 것** (대비 1.3:1, 거의 안 보임). 밝은 배경에는 딥 민트나 검정.

## 여백과 최소 크기

- **여백:** 로고 사방에 최소 *말풍선 안쪽 지름*만큼 비워 둔다.
- **최소 크기:** 심볼 16px(32px 이하는 `symbol-small.svg`), 가로형 너비 120px, 세로형 너비 80px.
- 16px에서는 말풍선 꼬리가 거의 사라지고 "a"로 읽힌다. 의도된 동작이다.

## 하지 말 것

- 비율 늘이기·눌리기, 회전, 기울이기
- 선 굵기 바꾸기, 외곽선만 남기기, 그림자·그라데이션·글로우 추가
- 워드마크를 다른 글꼴로 다시 쓰기 (워드마크는 심볼과 같은 둥근 선으로 직접 그린 것)
- 심볼과 워드마크 사이 간격·크기 비율 바꾸기
- 복잡한 사진 위에 바로 올리기 (잉크 타일 위에 얹을 것)

## 제작 메모

- 마스터는 **선(stroke) 기반**이다. 둥근 끝·둥근 이음이 형태의 일부라 그대로 두었다. 인쇄소나 커팅(자수, 스티커 칼선)용으로는 Illustrator/Figma에서 "선 윤곽선 만들기(Outline Stroke)" 후 넘길 것.
- 글꼴 라이선스 문제 없음: 워드마크는 글꼴이 아니라 도형으로 그렸다.
- **상표 검색은 하지 않았다.** 말풍선 모양은 메신저 앱에서 흔하므로, 확정 전에 상표 DB와 이미지 역검색으로 확인할 것.
